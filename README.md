## Contribute

Open a pull request with one self-contained `.html` file at the top level of the repo for each subject, exam type, and year. Use hyphens between words in the course name.

| Exam | Filename |
| --- | --- |
| Semester exam | `sem-YYYY-COURSECODE-course-name.html` |
| Cycle test | `ct-YYYY-COURSECODE-course-name.html` |

The library picks up new and updated analyses when the pull request merges into `main`.
