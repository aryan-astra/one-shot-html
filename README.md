# One Shot HTML

![Two students exploring a foldout HTML file with multiple-choice answers, green-highlighted questions, and a graph](assets/readme-html-foldout.png)

[Browse the SRM Exam Library](https://aryan-astra.github.io/one-shot-html/) to open student-made semester and cycle test analyses in your browser. Start with [Discrete Mathematics (21MAB302T) · SEM 2026](https://aryan-astra.github.io/one-shot-html/sem-2026-21MAB302T-discrete-mathematics.html).

To contribute, open a pull request with one self-contained `.html` file at the top level of the repo per subject, exam type, and year. Name it `sem-YYYY-COURSECODE-course-name.html` for semester exams or `ct-YYYY-COURSECODE-course-name.html` for cycle tests. Use hyphens between words in the course name. The library updates automatically after your pull request merges.
