# One Shot HTML

![Two students exploring a foldout HTML file with multiple-choice answers, green-highlighted questions, and a graph](assets/readme-cover.png)

Student-made question-paper analyses for SRM students revising for semester exams and cycle tests. Start with [Discrete Mathematics (21MAB302T) · SEM 2026](sem-2026-21MAB302T-discrete-mathematics.html). Download the HTML file and open it in a browser.

To contribute, open a pull request with one self-contained `.html` file per subject, exam type, and year. Name it `sem-YYYY-COURSECODE-course-name.html` for semester exams or `ct-YYYY-COURSECODE-course-name.html` for cycle tests. Use hyphens between words in the course name.
